# AsiaMart — интернет-магазин азиатских продуктов

Дипломный проект: интернет-магазин на **PHP + MySQL** с витриной товаров,
корзиной, оформлением заказа (имитация оплаты), регистрацией/входом
пользователей и админ-панелью.

![AsiaMart](public/assets/img/banners/hero_main.jpg)

---

## Стек технологий

| Слой | Технология |
|------|-----------|
| Бэкенд | PHP 8.2 (без фреймворка, чистый PHP + PDO) |
| База данных | MySQL / MariaDB |
| Управление БД | phpMyAdmin |
| Фронтенд | HTML5, CSS3 (без сборщиков), немного JavaScript |
| Шрифты | Fraunces, DM Sans, Noto Serif JP (Google Fonts) |

Дизайн — авторский стиль «Modern Ryokan»: тёплая бумажная палитра,
крупная серифная типографика, акцент-вермильон, японские иероглифы-акценты.

---

## Возможности

- 🏠 **Главная** — cinematic-hero, категории, хиты продаж, преимущества
- 🛍 **Каталог** — поиск, фильтр по категориям, сортировка (цена/новизна/популярность)
- 📦 **Страница товара** — галерея, описание, характеристики, похожие товары
- 🛒 **Корзина** — изменение количества, удаление, расчёт доставки
- 💳 **Оформление заказа** — форма доставки, выбор оплаты, **имитация оплаты**
- 👤 **Личный кабинет** — история заказов, личные данные
- 🔐 **Регистрация и вход** — пароли через bcrypt, защита CSRF
- ⚙️ **Админ-панель** — дашборд, CRUD товаров (с загрузкой картинок),
  управление заказами и пользователями
- 📄 Страницы «О нас», «Поддержка» (FAQ + форма), кастомная 404

## Установка (XAMPP / OpenServer / любой Apache+PHP+MySQL)

### 1. Скопировать файлы
Распакуйте архив и положите содержимое в папку веб-сервера:
- **XAMPP** → `C:\xampp\htdocs\asiamart\`
- **OpenServer** → `C:\OSPanel\domains\asiamart\`

> Корнем сайта должна быть папка `public/` (там лежит `index.php`).
> В XAMPP проще всего открывать через `http://localhost/asiamart/public/`.

### 2. Создать базу данных
1. Запустите Apache и MySQL (через панель XAMPP / OpenServer).
2. Откройте **phpMyAdmin** → `http://localhost/phpmyadmin/`
3. Вкладка **«Импорт»** → выберите файл `sql/asiamart_full.sql` → **«Вперёд»**.

Это создаст базу `asiamart` со всеми таблицами и данными (24 товара, 4 категории,
2 пользователя, демо-заказы).

### 3. Настроить подключение
Откройте `includes/config.php`. Для локального XAMPP/OpenServer
обычно подходит **root без пароля** — раскомментируйте ВАРИАНТ 1:

```php
define('DB_HOST', '127.0.0.1');
define('DB_PORT', 3306);
define('DB_NAME', 'asiamart');
define('DB_USER', 'root');
define('DB_PASS', '');
```

(и закомментируйте ВАРИАНТ 2 ниже).

### 4. Открыть сайт
`http://localhost/asiamart/public/`

## База данных

6 таблиц:

- **users** — пользователи (роль `user` / `admin`, bcrypt-пароли)
- **categories** — категории товаров
- **products** — товары (цена, скидка, остаток, страна, вес, рейтинг)
- **cart_items** — корзина (привязка к пользователю или к сессии гостя)
- **orders** — заказы (контакты, адрес, способ оплаты, статус, сумма)
- **order_items** — состав заказа

## Проверка проекта

Перед загрузкой на GitHub или сервер можно запустить локальные проверки:

```bash
php tests/run.php
```

Тесты проверяют версию PHP, расширения `mbstring` и `pdo_mysql`, синтаксис PHP-файлов
и соответствие ключевых SQL-полей коду магазина.

Если PHP в Windows не добавлен в `PATH`, для OpenServer можно использовать:

```powershell
& 'C:\OSPanel\modules\php\PHP_8.1\php.exe' -d extension_dir='C:\OSPanel\modules\php\PHP_8.1\ext' -d extension=mbstring -d extension=pdo_mysql tests\run.php
```

## Примечания

- **Оплата — имитация**: реальные платёжные системы не подключены, заказ
  сразу помечается как «оплачен». Это допустимо для дипломного проекта.
- Папка `phpmyadmin/` включена для удобства, но если на вашем сервере
  phpMyAdmin уже установлен — её можно удалить.
- Файл `public/adminer.php` — лёгкая альтернатива phpMyAdmin (один файл),
  тоже можно удалить.
