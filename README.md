# AsiaMart — интернет-магазин азиатских продуктов

Дипломная разработка: каталог, корзина, оформление заказа, личный кабинет
и админ-панель. Бэкенд — PHP 8 + MySQL/MariaDB. Фронтенд — Bootstrap 5,
jQuery 3, jQuery UI 1.13.

## Требования к серверу

- PHP ≥ 8.0 (с расширениями `pdo_mysql`, `mbstring`, `session`)
- MySQL ≥ 5.7 или MariaDB ≥ 10.3
- Любой веб-сервер (Apache, Nginx, или встроенный PHP-сервер для тестов)

## Развёртывание на хостинге

1. **Создайте базу данных** через панель управления (например, phpMyAdmin):
   - Имя БД: `asiamart`
   - Пользователь: `asiamart`
   - Пароль: придумайте свой и пропишите его в `php/config.php`
2. **Импортируйте схему**: загрузите `sql/schema.sql` через phpMyAdmin
   (вкладка «Импорт»). Это создаст таблицы и заполнит тестовыми
   данными: 4 категории, 24 товара, 2 пользователя.
3. **Загрузите файлы сайта** в корень домена (`public_html` / `www`).
4. **Отредактируйте `php/config.php`** — впишите реальные параметры БД
   (host, name, user, password).
5. **Настройте права**: каталог `php/` и файлы сессий должны быть
   доступны для записи веб-сервером (обычно достаточно настроек по
   умолчанию).
6. Откройте сайт в браузере — главная страница доступна как `/` или `/index.php`.

## Локальный запуск

```bash
# из директории site/
php -S 127.0.0.1:8000
```

Откройте http://127.0.0.1:8000

## Реализованный функционал

- Регистрация и вход пользователей (bcrypt + сессии + CSRF-токены)
- Каталог товаров с фильтром по категориям и поиском
- AJAX-корзина (jQuery): добавление, изменение количества, удаление
- Корзина для гостей хранится в сессии, для авторизованных — в БД
- Оформление заказа: выбор доставки (курьер/самовывоз) и оплаты
  (картой/наличными), бесплатная доставка при заказе от 3000 ₽
- Личный кабинет с историей заказов и их статусами
- Админ-панель: дашборд, CRUD товаров, управление статусом заказов,
  управление ролями пользователей
- Разграничение доступа по ролям (`user` / `admin`)
